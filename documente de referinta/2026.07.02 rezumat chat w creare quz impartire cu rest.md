## Notație

```
d : i = c  r   →   deîmpărțit : împărțitor = cât  rest
d = i * c + r
```

Variabile în cod: `d`, `i`, `c`, `r`.

---

## Ce e implementat (stare 2026.07.02)

### Generare fapt

- **Nivel 1…9** → împărțitor fix `i = nivel + 1` (niv 1 → i=2 … niv 9 → i=10)
- **Cât `c`:** random 2–10 (`MIN_C`, `MAX_C`)
- **Rest `r`:** valid = **`0 ≤ r < i`** (strict mai mic decât împărțitorul)
  - ~**15%** șanse rest 0 (`REST_ZERO_CHANCE = 0.15`)
  - altfel random din `1 … i-1`
- **Deîmpărțit `d`:** calculat `d = i * c + r`
- Validare: `isValidFact()` — refuză fapte inconsistente

### Afișare întrebare

- **O singură** equation form per pas
- **2 fact forms**, alegere **random**:
  1. Cu `:` — ex. `32:5=6 r 2` (în UI scrie **`r`**, nu „rest”)
  2. Cu `*` — ex. `32=5*6+2` (ordine fixă: `d=i*c+r`)
- **8 equation forms** = 2 forms × 4 poziții pentru `?` (d, i, c, r), alegere **random**
- Fiecare formă apare în **notația ei** (nu convertim `:` → `*` la afișare)

Exemple poziții `?`:

| Poziție | Form `:` | Form `*` |
|---------|----------|----------|
| d | `?:5=6 r 2` | `?=5*6+2` |
| i | `32:?=6 r 2` | `32=?*6+2` |
| c | `32:5=? r 2` | `32=5*?+2` |
| r | `32:5=6 r ?` | `32=5*6+?` |

### Răspunsuri

- **3 butoane** (1 corect + 2 capcane)
- Capcane **doar** pe poziția unde e `?`
- Reguli capcane (cu fallback dacă ±delta dă invalide/duplicate):
  - **d:** ±15, ≥ 1
  - **i, c:** ±3, ≥ 2 (niciodată 0 sau negativ)
  - **r:** din `{0 … i-1}` \ {corect}, sortate după distanță de corect

### Contoare și niveluri

| Contor | Regulă |
|--------|--------|
| `questionCount` | +1 la **fiecare răspuns** (corect, greșit, retry) |
| `consecutiveCorrect` | +1 doar la corect; **reset la 0** la greșeală |

**Trecere nivel** (contoare resetate la nivel nou):

1. `questionCount >= 21` — verificat **imediat după increment**, la **orice** răspuns (corect sau greșit). Dacă al 21-lea e greșit → nivelul se termină, **fără retry**.
2. `consecutiveCorrect >= 5` — doar după răspuns **corect**, și doar când `questionCount < 21`.

**Timeout lift:** reset bară, aceeași întrebare, **fără** increment contoare.

### Greșeală → retry

- **1 singur retry** dacă `questionCount < 21` după greșeală
- Același fapt `{d,i,c,r}`, aceeași poziție `?`, **alt fact form** (`:` ↔ `*`)
- Greșeală la retry → întrebare nouă, fără al doilea retry

### Ce NU e implementat (din spec / discuții)

- Ponderi 50%/75% pentru fact forms (șters din spec — acolada „ignoră”)
- Formele 3–5 cu reordonări (`r+i*c`, etc.)
- EFF, mastery, persistență, gestionareGreseli
- Teste automate
- Progress vizual pentru streak (doar bară procent 21 întrebări)
